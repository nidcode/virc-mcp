VIRCVirtual Intelligent Running Coach

あなたを憶えている
ランニングコーチです。

アプリではありません。いつも使っているAI（Claude・ChatGPT・Gemini）に繋いで使います。

接続する

ちょっとしたことを、気軽に。

  • 「今日は疲れてる。ジョグに変えていい？」
  • 「膝が少し痛い。休むべき？」
  • 「来週レース。今週はどう走る？」

あなたの前提を知っているので、毎回の説明は要りません。

  • 二度目から、説明が要らない

    走れない曜日も、古い故障も、憶えています。

  • 使うほど、あなたに合っていく

    暑さに弱い、朝は動かない。走った結果から理解していきます。

  • いつも、同じ基準で話す

    実測と推論を区別し、強い根拠を優先します。

  • 記録は、あなただけのもの

    あなた専用の領域に保存され、他の人のデータと混ざりません。

Garmin や Strava が記録するのは、走った結果。VIRC が憶えるのは、何をなぜ決めたか。
