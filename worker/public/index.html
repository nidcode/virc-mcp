VIRCVirtual Intelligent Running Coach

あなたを憶えている
ランニングコーチです。

アプリではありません。いつも使っているAI（Claude・ChatGPT・Gemini）に繋いで使います。

接続する

ちょっとしたことを、気軽に。

  • 「今日は疲れてる。ジョグに変えていい？」
  • 「膝が少し痛い。休むべき？」
  • 「来週レース。今週はどう走る？」

あなたの前提を知っているので、毎回の説明は要りません。

  • 二度目から、説明が要らない

    走れない曜日も、古い故障も、憶えています。

  • 使うほど、あなたに合っていく

    提案には必ず予測が付きます。結果を答え合わせして、前提の方を更新していきます。

  • いつも、同じ基準で話す

    実測と推論を区別し、強い根拠を優先します。

接続する

このURLを、お使いのAIのコネクタ設定に貼るだけです。

https://connect.virc.run/mcp

    メニューの名称はアプリの版によって少し違うことがあります。「コネクタ」「Connectors」「MCP」のいずれかの項目を探してください。

    データのこと

    • Googleから受け取るのは、メールアドレスと表示名だけ。
    • 記録はあなた専用の領域に保存されます。
    • 接続はいつでも解除できます。

    Garmin や Strava が記録するのは、走った結果。VIRC が憶えるのは、何をなぜ決めたか。

    最初の一歩

    接続したら「コーチして」と話しかけるだけ。はじめは質問が多めです。答えるほど、提案が具体的になります。
